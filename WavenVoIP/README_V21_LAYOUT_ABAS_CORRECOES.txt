Versão v21 - atualizações aplicadas sobre a v19 funcional:

- Tela principal reorganizada em abas: Discagem, Contatos, Histórico e Configurações.
- Removido menu lateral da tela principal.
- Discador ajustado para não cortar números dos botões.
- Tela de chamada recebida ampliada para não cortar informações.
- Tela de WhatsApp redimensionada, com campo de mensagem iniciando no topo e ícone visual de WhatsApp.
- Tela de escolha de saída aumentada para não cortar o botão Cancelar.
- Tela de chamada: botão Desligar centralizado com símbolo de gancho, sem texto.
- Mantidas correções da v19 de chamada recebida, toque e popup de chamada perdida.

Observação:
- Esta versão foi feita a partir do último ZIP funcional enviado pelo usuário (v19).
- Ao testar no Visual Studio, extraia em uma pasta nova e abra o projeto dali. Não misture com pastas antigas para evitar arquivos XAML duplicados.
