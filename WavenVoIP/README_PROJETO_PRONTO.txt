PROJETO PRONTO PARA EXTRAIR NO VISUAL STUDIO

O pacote foi ajustado para que Models, Services e Views fiquem DENTRO de:
src/WavenVoIP/

Abra a solução/projeto em:
src/WavenVoIP/WavenVoIP.csproj

Se o Visual Studio estiver aberto:
1. Feche o projeto
2. Extraia este zip por cima da pasta atual
3. Abra novamente o .csproj
4. Compilação > Limpar Solução
5. Compilação > Recompilar Solução
