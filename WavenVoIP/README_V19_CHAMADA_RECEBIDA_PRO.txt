Waven VoIP - V19 chamada recebida PRO

Ajustes aplicados:
- Tela de chamada recebida refeita no estilo iPhone/3CX.
- Botões circulares Atender e Recusar.
- Popup fica no canto inferior direito e para o toque ao fechar.
- Popup fecha automaticamente quando o Issabel envia CANCEL/BYE, ou seja, quando a chamada deixa de existir, cliente desliga ou outro atendente atende.
- Notificação lateral de chamada perdida quando o usuário recusa/fecha uma chamada pendente.
- Tela de ligação ajustada com botão WhatsApp no lugar de áudio principal e botão Desligar centralizado estilo iPhone.
- Tela WhatsApp redimensionável para não cortar botões.
- Datas do histórico em formato brasileiro dd/MM/yyyy HH:mm.

Observação:
Não foi possível compilar neste ambiente Linux porque o projeto é WPF/Windows. Compile no Visual Studio no Windows.
